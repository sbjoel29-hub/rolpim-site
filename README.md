# The Pathway of Life Revealed — Marketing Website

Ready-to-deploy static website for Pastor Collins O. Ben-Zion's book, "The Pathway of Life Revealed."

## What's inside
- `index.html` — the full one-page site
- `style.css` — all styling (coral/teal/navy/gold palette matching the book cover)
- `script.js` — mobile menu + footer year
- `img/` — all 5 images you provided, optimized for web (resized + compressed, ~150-280KB each instead of multi-MB originals)

## How to publish it (pick one — all are free for a simple site like this)

**Netlify (easiest):**
1. Go to https://app.netlify.com/drop
2. Drag the whole `rolpim-site` folder onto the page
3. You get a live URL in seconds; you can add a custom domain (e.g. rolpim.org or pathwayoflife.com) in Netlify's settings afterward

**GitHub Pages:**
1. Create a new GitHub repository
2. Upload these files
3. In repo Settings → Pages, enable Pages on the main branch

**Your own hosting / cPanel:**
Upload the whole folder via FTP into your site's `public_html` (or equivalent) directory. No build step needed — it's plain HTML/CSS/JS.
